# Changesets

Add a changeset for every user-facing change to `@vp-tw/dirwell`:

```bash
pnpm changeset
```

Select the package, choose the intended version impact, and write a concise
release note. Changesets remain in prerelease mode under the `alpha` tag until
the project explicitly decides to publish a stable version. See
[RELEASING.md](../RELEASING.md) for the release steps.
