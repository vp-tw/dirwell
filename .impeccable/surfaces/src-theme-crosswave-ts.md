# Crosswave theme

Mode: Operate. New opt-in packaged theme; Ledger, Plain, generator contracts, URL policy, and static hosting remain fixed. The user pins the PSP crossbar navigation and luminous ribbon background, requests directory-page transitions, responsive behavior, and gamepad navigation with synthetic browser verification. Use original geometric icons and procedural light; no console assets, firmware meshes, fake battery indicators, or sound.

## Direction contract

THESIS: A folder becomes a media shelf: move horizontally through real file categories and vertically through native file links. PSP navigation is explicitly pinned by the user, overriding the general Operate topology default.

OWN-WORLD: Saturated midnight azure, white geometric category icons, soft directional shadows, translucent satin ribbons, and quiet system sans labels. Broad empty space separates the selected item from its metadata.

STORY: Browse a folder, select a category, find a file, and open it. All files remain ordinary links; source names and link states stay visible.

FIRST VIEWPORT: Location and real clock above a horizontal icon rail; selected category above a vertical file list; selected-file details to its right; a slowly lit ribbon spans the lower background. Narrow screens retain a horizontally scrollable category rail and one usable file column.

FORM: User-pinned PSP XMB, code-led; no concept seed or generated comp. Research references are Sony's XMB manual, shader community approaches, cross-document View Transitions, and VueUse useGamepad. Signature interaction: category focus slides on one axis, directory content exchanges through a shared background snapshot.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Acceptance: packaged factory; actual SSG/MPA/URL navigation; search and empty/error/link states; IME-safe keyboard and touch; optional wave pause and reduced motion; hidden-page and WebGL failure fallbacks; cross-document transitions; virtual gamepad connect/hold/release/confirm/back/disconnect; no hardware gamepad claim. Browser captures: desktop, 390px portrait, and narrow landscape. The background is code-native and ships no raster assets.

Approved extension: persistent directory shell with opposite entry/parent directions, native history restoration, bounded visible-row animation snapshots, on-demand generated script data for SSG/MPA and relative local files, cancellable latest-request navigation, eight-second timeout, retained-list retry/native-link errors. No new palette, icons, shader, or backend.

Approved extension: configurable category labels/order/visibility, built-in or trusted decorative SVG rail icons, overlapping extension/MIME filters, arbitrary IDs and first-category selection. Node-only mime 4.1.0 classification; browser receives membership IDs, not the database. Core file response headers and content sniffing are unchanged. Custom rail icons do not replace inferred file-row glyphs. Custom example uses the existing Jade palette and original small SVG; no new visual system.

Approved extension: fixed-footer theme attribution, Crosswave by VdustR, with native links to the theme README and author profile. Credits use the existing Muted foreground and 12px secondary-label type, underlined links with 44px minimum target heights, and the incumbent focus outline. Portrait places credits above appearance controls; short landscape keeps both on one row. Credits are static HTML and remain available without JavaScript. Enhanced layout measures the footer height so status and navigation notices stay above it. Desktop, 390px portrait, and short-landscape evidence is in `.impeccable/review/credits/`; this ordinary extension preserves the Crosswave design system and its sidecar. Axe reports zero violations, with gradient-background contrast remaining incomplete rather than independently certified by that scan.
