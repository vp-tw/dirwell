Dirwell turns a directory into a static, accessible file explorer. Use it for
release downloads, generated artifacts, documentation attachments, or any
folder that needs a useful web interface without an application server.

SSG means static site generation: it writes portable pages with assets in
each directory. MPA means multi-page application: directory pages share
runtime assets under one output root. Both modes write static files.

## Defaults

- One-command local server with file watching and live reload.
- Deployable SSG output; choose MPA when pages should share runtime assets.
- Fuzzy search, IME-safe keyboard input, linked breadcrumbs, and color-scheme controls.
- Explicit broken, cyclic, and out-of-root symlink states.
- Relative, deployment-base, and native HTML `<base>` URL strategies.
- Typed theme components that can be wrapped or replaced.
