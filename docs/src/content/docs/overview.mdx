Dirwell turns a folder into a website where visitors can browse directories,
search for files, and open the original downloads. Use it for release files,
reports, generated artifacts, or documentation attachments.

[Try the live explorer](https://vp-tw.github.io/dirwell/examples/file-icons/) or
[build your first explorer](../getting-started/).

## What you get

- A page for each directory, with breadcrumbs and links to its files.
- Search, sorting, file icons, and keyboard navigation in the default theme.
- A local server that updates as the source folder changes.
- Static HTML and assets you can publish without running a Dirwell server.

The first command needs no config. You need Node.js 26 or later to run Dirwell;
visitors only need a browser. Use the published package without a prerelease tag.

## Customize after the first build

Keep the defaults until you need a different result. Configuration controls file
selection and URL layout. Themes control appearance and browser behavior.
Build adapters let Dirwell run alongside an existing application.
