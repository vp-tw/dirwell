Dirwell turns folders into browsable websites. Use live server mode for a local folder or build portable HTML for release downloads, reports and artifacts.

The published `@dirwell/*` packages are currently alpha. Use Node.js 22.12 or later and the `alpha` tag. The CLI includes Plain: native links and pagination without browser JavaScript. Install Ledger or Crosswave separately for search, sorting and keyboard navigation.

[Start with the CLI](../getting-started/) or [compare working examples](../examples/).

Static output needs no Dirwell server. Live mode reads filesystem data on requests and does not generate an output tree. Optional rich-client updates use SSE; static builds must be rebuilt after source changes.
