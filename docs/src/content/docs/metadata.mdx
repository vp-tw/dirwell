---
title: Page metadata and share images
description: Opt into build-time titles, descriptions, canonical URLs and images.
---

Metadata and PNG rendering live in optional `@dirwell/share-image`. Core and themes do not install it. Plain emits no social metadata or image assets by default.

```sh
npm install --save-dev @dirwell/core@alpha @dirwell/theme-plain@alpha @dirwell/share-image@alpha
```

```js
import { generateExplorer } from "@dirwell/core";
import { createPlainTheme } from "@dirwell/theme-plain";
import { createMetadataProvider } from "@dirwell/share-image";

await generateExplorer({
  sourceDir: "files",
  outputDir: "public/downloads",
  theme: createPlainTheme(),
  metadata: createMetadataProvider(
    { siteName: "Downloads", siteUrl: "https://example.com/downloads/" },
    { siteName: "Downloads", repositoryName: "you/downloads", imageTheme: "plain" },
  ),
});
```

`siteUrl` is the deployed explorer root, including its prefix. It supplies absolute canonical and share URLs. Use a content name, not just a theme name. Titles identify the current folder; describe direct folder contents separately from archive-wide totals shown on a shared cover.

## Text and fixed covers

`title` and `description` accept strings or async callbacks. Callbacks receive `site` archive counts and `directory` direct counts/path. Omit `imageTheme` for text-only metadata. `image: false` disables a preset. A local path, file URL or File supplies a custom image; an object adds `outputPath` and `alt`.

When using relative image paths, pass the intended source directory as the third argument to `createMetadataProvider`. Metadata resolves before output replacement. Image bytes are deduplicated per build and conflicting output paths are rejected.

## Per-folder images

```js
import { createMetadataProvider, createShareImage, describeContent } from "@dirwell/share-image";

export const metadata = createMetadataProvider(
  {
    siteName: "Design kit",
    siteUrl: "https://example.com/design/",
    description: ({ directory }) => describeContent(directory),
    image: async ({ directory, site, description }) => ({
      source: await createShareImage({
        theme: "crosswave",
        title: directory.relativePath || site.name,
        description,
        directoryPath: directory.relativePath,
      }),
      outputPath: `og/${directory.relativePath || "root"}.png`,
      alt: `${directory.relativePath || site.name}: ${description}`,
    }),
  },
  { siteName: "Design kit", repositoryName: "you/design" },
);
```

Use this provider as `build.metadata`, core `metadata` or adapter `metadata`. See the [dynamic image demo](../examples/). This is build-time rendering, not a live server image endpoint.

Presets generate 1200 × 630 PNGs using bundled fonts without network/system-font lookup. Unsupported glyphs fail rather than silently becoming missing characters. Use a custom renderer for other scripts. `createShareImage` returns a PNG File; optional image dependencies stay outside Core/Plain.
