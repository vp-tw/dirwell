Each `config.ts` exports core `GenerateOptions` using the published SDK. The site build calls `generateExplorer` for each example before Astro copies the output to the publish tree. The Ledger source example compiles its wrapper with the optional authoring package first. These TypeScript API configs are not CLI configuration files.

## Run one example

From an [installed repository checkout](https://github.com/vp-tw/dirwell/blob/main/CONTRIBUTING.md):

```sh
node scripts/build-example.ts file-icons ./generated-example
```

Build replaces the dedicated output directory. Serve the complete result over HTTP. The base example requires its configured mount. For a standalone CLI project, use `dirwell.config.mjs` with `theme`, `build`, `server` and `listing` sections.

## Build the complete site

```sh
SITE_BASE=/dirwell/ pnpm site:build
```

`pnpm docs:dev` rebuilds examples, starts Astro and watches package/example inputs. `SITE_BASE` sets the documentation prefix. `PUBLIC_REPOSITORY_URL` controls source links; GitHub Actions supplies the repository URL.
