## Build a static example

Each source directory includes a README and a TypeScript `config.ts` that selects its theme, input folder and output. These configs use the Dirwell API; they are not CLI configuration files.

From an [installed repository checkout](https://github.com/vp-tw/dirwell/blob/main/CONTRIBUTING.md):

```sh
node scripts/build-example.ts file-icons ./generated-example
```

Serve the complete `generated-example` directory over HTTP. For the URL-prefix example, use the `/examples/base/` path described in its README so its links resolve correctly.

To build your own folder without a repository checkout, follow [Getting started](../getting-started/). To work on the Dirwell documentation website, see [Contributing](https://github.com/vp-tw/dirwell/blob/main/CONTRIBUTING.md).
