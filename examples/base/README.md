# Base URL example

This example uses MPA output with shared assets and a deployment base. Set
`DIRWELL_SITE_BASE` to the site's base path before building.

```bash
DIRWELL_SITE_BASE=/dirwell/ node ../../src/bin.ts build --cwd .
```

- [Live demo](https://vp-tw.github.io/dirwell/examples/base/)
- [Source code on GitHub](https://github.com/vp-tw/dirwell/tree/main/examples/base)
